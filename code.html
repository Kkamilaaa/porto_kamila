SIYUDIS: Sistem Informasi Yudisium

SIYUDIS is an information system that supports the student graduation (yudisium) process at the Department of Electrical Engineering and Informatics, SV UGM, and it is developed under the department’s supervision. I work on it as both Project Manager and QA Automation Engineer for a team of seven. On the management side, I keep the product backlog and the Work Breakdown Structure (WBS) in order and prepare the technical documentation, including the Software Requirements Specification (SRS), activity diagrams, and use case diagrams. On the quality side, I write the test cases, run automated API tests in Postman, and use Playwright for end to end testing, so we can be confident that the system works as intended and stays reliable.

For Fanina Veterinary Clinic, I led a team of four in building a web based business management system.
